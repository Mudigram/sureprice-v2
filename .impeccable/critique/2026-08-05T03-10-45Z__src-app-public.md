#### Overall Impression

SurePrice V2's public shopper app delivers a fast, physical-first experience tailored for Nigerian brick-and-mortar stores. The core camera scanning and in-store price checklist model feel authentic and practical. Polishing header back-navigation for external QR deep links, adding safety confirmation for destructive list clearing, standardizing icon semantics (`ClipboardList` vs `ShoppingCart`), fixing accessibility labels, and eliminating undersized text floors will elevate the public app from Good to Excellent.

#### What's Working

1. **Authentic In-Store Shopping Checklist Model**: `CartContext` provides real-world physical retail utility—shoppers check off items as they pick them up, view per-store subtotals, save store trips, and export plain-text lists for WhatsApp sharing.
2. **Zero-Friction Fast Camera Scanning**: Instant camera initialization on `/scan` with optical laser beam animation, torch toggle, manual code fallback, and sub-second `/q/[code]` shortcode resolution.
3. **Venue-Tailored Storefront Badging**: Retail, restaurant, and pop-up vendor cards render with venue-specific visual badges and color cues (lime/slate for retail shelf tags, amber for dining menus, purple for event vendor stalls).

#### Priority Issues

- **[P1] Header Back Button Fails on External Direct QR Landings**
  - **Why it matters**: Tapping "Back" on `DynamicHeader` calls `router.back()`. When shoppers scan a physical QR code with native phone camera, Next.js session history is empty (`history.length <= 1`), causing the button to do nothing or exit the webview.
  - **Fix**: Check `window.history.length <= 1` and fallback to `/s/${businessSlug}` or `/stores`.
  - **Suggested command**: `$impeccable adapt`

- **[P1] Destructive "Clear All" Executed Without Confirmation**
  - **Why it matters**: A single mis-tap on "Clear All" in `/cart` immediately wipes all saved items across stores with zero undo path.
  - **Fix**: Require a modal confirmation dialog before executing `clearList()`.
  - **Suggested command**: `$impeccable harden`

- **[P2] Accessibility Gaps: Unlabeled Icon Buttons & Div Action Clickers**
  - **Why it matters**: Icon buttons on `/cart` (`<Minus>`, `<Plus>`, `<Trash2>`), camera torch toggle, and thumbnail gallery buttons lack `aria-label`. Expandable trip history cards use `<div onClick>` without `role="button"` or `tabIndex={0}`.
  - **Fix**: Add `aria-label` to all icon buttons and `role="button"` + keyboard handlers to clickable divs.
  - **Suggested command**: `$impeccable audit`

- **[P2] Confusing "List" Tab Icon (ShoppingCart vs In-Store Checklist)**
  - **Why it matters**: `BottomNav` labels the 3rd tab "List" but uses `ShoppingCart`, misleading first-time users into expecting online e-commerce delivery instead of in-store price checks.
  - **Fix**: Replace `ShoppingCart` icon with `ClipboardList` or `CheckSquare`.
  - **Suggested command**: `$impeccable clarify`

- **[P2] Manual Code Input Hidden Behind Extra Accordion Tap on Camera Failure**
  - **Why it matters**: When camera permission is denied, the manual shortcode input stays hidden inside a collapsed accordion.
  - **Fix**: Auto-expand `showManual` state to `true` whenever camera status reaches `'denied'` or `'error'`.
  - **Suggested command**: `$impeccable adapt`

- **[P3] Undersized Functional Text Floor (<11px)**
  - **Why it matters**: 21 instances of `text-[9px]` and `text-[10px]` make badges, metadata, and timestamps hard to read on mobile screens under outdoor ambient light.
  - **Fix**: Bump text floor to `text-xs` (12px) or `text-[11px]`.
  - **Suggested command**: `$impeccable typeset`

#### Persona Red Flags

- **Jordan (Confused First-Timer)**: The `ShoppingCart` icon on the bottom nav tab labeled "List" creates an expectation of online e-commerce checkout. Jordan looks for a "Pay Now" button on `/cart` instead of recognizing it as an in-store reference checklist.
- **Casey (Distracted Mobile User)**: In a bright, noisy supermarket, if camera permission fails, Casey must discover and tap the collapsed manual code accordion toggle. Additionally, search input styling varies between `/stores` (green-tinted `bg-green-100/50`) and `/cart`/`/scan` (dark slate).
- **Riley (Stress Tester)**: Tapping "Clear All" on `/cart` instantly deletes 50+ items without confirmation. Scanning a QR shortcode in a fresh browser tab breaks top-left header navigation because `router.back()` has no previous page to return to.

#### Minor Observations

- **CSS Utility Syntax**: `ScanButton.tsx` uses Tailwind v4 syntax `bg-(--lime-base)` with parentheses, while all other components use standard `bg-[var(--lime-base)]`. Standardizing prevents parser inconsistencies.
- **Emoji Accessibility**: Emojis used across `store-detail-client.tsx` and `item-detail-client.tsx` (`☕`, `🥤`, `🍽️`, `🎪`, `📦`) lack `role="img"` or `aria-hidden="true"`.
